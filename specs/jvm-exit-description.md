## Проблема

Закрытие окна не завершает JVM. Процесс продолжает жить и держать память.

Наблюдалось дважды за один день:

| Когда | Удержание |
|---|---|
| 2026-10-07, первый раз | **24,2 ГБ** (208% физической памяти) |
| 2026-10-07, второй раз | **17,9 ГБ** |

После закрытия окна процесс остаётся, следующий запуск падает с
`IllegalStateException: The file is locked` на `h2db.mv.db`, пока процесс
не убить вручную.

## Требование

Главное окно: при закрытии приложение завершается.

- Обработчик закрытия окна вызывает завершение JVM.
- База освобождается сразу, следующий запуск проходит без ошибки.
- Дочерние процессы ffmpeg и Python не остаются висеть.

## Замечание

Проблема зафиксирована в `docs/adr/0005-sequential-threads-no-pool.md`
(раздел «Закрытие окна не завершает JVM») как долг. Задача его снимает.
