## Задача

Шаг 2 из плана «привести проект к рабочему состоянию»: покрыть проект
живой документацией (SSoT). Сейчас её нет вообще.

## Что должно появиться

1. **Карта доменов** — по факту существующего кода, не по идее:
   проект → файл → кадр → план → сцена/событие → лицо → персона →
   фильтр → универсальные свойства.
2. **ADR** на четыре решения, которые в проекте приняты неявно и потому
   неочевидны при чтении кода:
   - ручной `AnnotationConfigApplicationContext` вместо Spring Boot;
   - схема `*Cdf` (per-machine пути через `Main.ccid`);
   - приложение запускается только из `target/classes`, не из jar;
   - пороги распознавания лиц (0.45 + минимальный отрыв 0.05).
3. Описание текущего состояния: InsightFace + ONNX, `FaceTrack`,
   кеш моделей. Отчёты в `legacy-analysis/` — историческая справка о
   состоянии 2022 года, а не описание текущего кода.

## Критерий готовности

Документ отвечает на вопрос «что это за проект и как он устроен»
без чтения исходников, и не содержит утверждений, противоречащих коду.
