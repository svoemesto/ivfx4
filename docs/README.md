## Что это за проект

**ivfx** — настольное JavaFX-приложение для кинематографического анализа
видеоархива. Оно раскладывает видеофайлы на кадры, автоматически находит
границы **планов** и **сцен**, детектирует и распознаёт **лица**, сводит всё в
реляционную базу, даёт оператору интерфейс для ручной доводки результата и
умеет собрать **выборку фильтра в один видеофайл**.

Пользователь один, приложение локальное, сетевого слоя нет.

| | |
|---|---|
| Стек | Maven, Kotlin 1.5.31, Spring Boot 2.5.6 (как контейнер, не как фреймворк), JavaFX 11, JPA + H2/Postgres |
| Сборка | `~/.local/opt/apache-maven-3.9.16/bin/mvn`, JDK 18 |
| Запуск | `bash run-old-app.sh` — **только из `target/classes`, не из jar** (ADR-0004) |
| Проверки | `bash tools/check-fx-wiring.sh`, `python3 docs/scripts/lint-docs.py` |
| Задачи | OpenProject, проект IVFX (`project-id: 5`) |

### 3. Решения (ADR)

| ADR | Решение | Статус |
|---|---|---|
| [ADR-0001](adr/0001-manual-spring-context.md) | Spring-контекст поднимается вручную, Spring Boot не используется как фреймворк | принято |
| [ADR-0002](adr/0002-per-machine-paths-cdf.md) | Пути к рабочим папкам хранятся per-machine через схему `*Cdf` | принято, устаревает |
| [ADR-0003](adr/0003-face-models-not-in-git.md) | Модели распознавания не хранятся в репозитории, а кешируются на машине | принято |
| [ADR-0004](adr/0004-run-from-classes-not-jar.md) | Приложение запускается только из `target/classes`, не из банка | принято, обходной путь |
| [ADR-0005](adr/0005-sequential-threads-no-pool.md) | Обработка идёт последовательными потоками без пула и без рабочей отмены | принято, долг |

## Для агентов: порядок работы

1. Прочитать **этот** файл.
2. Определить домен по карте выше.
3. Прочитать `domains/<домен>/domain.md` и связанные ADR.
4. Только после этого идти в код.

Ответ начинается с пометки `[SSoT-Verified]`, если документация была
действительно прочитана, а не только просмотрена.

### Жизненный цикл изменения

```
Ephemeral  → черновики вне docs/ (specs/, трекер OpenProject)
Mutation   → вместе с реализацией обновлены docs/ (домены, ADR, рецепты)
Purge      → временные артефакты удалены
```

Слияние не считается завершённым, пока документация не обновлена.

### Проверки перед коммитом

```bash
python3 docs/scripts/lint-docs.py     # структура документации
bash tools/check-ktlint.sh             # стиль Kotlin, отпечаток состояния
bash tools/check-fx-wiring.sh         # связь FXML и контроллера, сборка
~/.local/opt/apache-maven-3.9.16/bin/mvn -q clean compile
```

Правила проекта целиком — в [`AGENTS.md`](../AGENTS.md).
