# Линтеры и отпечаток состояния

## Что подключено

| Линтер | Что проверяет | Команда |
|---|---|---|
| `tools/check-fx-wiring.sh` | связь FXML и контроллера, сборка | `bash tools/check-fx-wiring.sh` |
| `tools/check-ktlint.sh` | стиль Kotlin, без ложных срабатываний на легаси | `bash tools/check-ktlint.sh` |
| `docs/scripts/lint-docs.py` | структура документации | `python3 docs/scripts/lint-docs.py` |

## Почему у ktlint свой отпечаток, а не встроенный

Проект написан в 2021–2022 годах в компактном стиле, который не совпадает
с официальным ktlint. Наивное подключение выдаёт **8036 нарушений** разом —
это блокирует любую работу, а не помогает.

Встроенный `--baseline` ktlint 1.5.0 в этом проекте **не сработал**: проверено
на одном файле с абсолютными и относительными путями — подавление нулевое,
число нарушений не менялось. Поэтому отпечаток свой, в `tools/ktlint-baseline.py`.

## Чем отпечаток отличается от наивного

1. **Привязан к паре (файл, правило) и счётчику**, а не к номеру строки.
   Правка соседних строк его не ломает.
2. **Считает количество.** Если правило встречалось в файле 3 раза, а стало
   4 — это новое нарушение, оно попадёт в отчёт. Наивный отпечаток по паре
   (файл, правило) такое пропустил бы.
3. Синтаксические ошибки у ktlint идут без имени правила; они сведены в один
   счётчик «синтаксическая ошибка».

## Размер долга

Отпечаток: `config/ktlint/baseline.xml`, 93 КБ, 8036 записей в 138 файлах.
Крупнейшие правила:

| Нарушений | Правило |
|---|---|
| 1474 | `argument-list-wrapping` |
| 950 | `indent` |
| 650 | `function-signature` |
| 561 | `chain-method-continuation` |
| 386 | `wrapping` |
| 359 | `max-line-length` |
| 329 | `binary-expression-wrapping` |

Почти всё — форматирование. Прикладная часть — 176 неиспользуемых импортов;
их выгоднее вычищать первыми, они безопасны и заметно полезнее выравнивания.

## Как сокращать долг

```bash
# 1. починить нарушения в конкретных файлах
# 2. пересчитать отпечаток — записи по этим файлам исчезнут
bash tools/update-ktlint-baseline.sh
```

Запускать пересчёт «просто так» нельзя: отпечаток вслепую примет и новые
нарушения, и защита перестанет работать.

## Установка линтера

Бинарь ktlint — 70 МБ, в git не коммитится:

```bash
bash tools/install-ktlint.sh      # версия из tools/ktlint/VERSION (1.5.0)
```

## Ограничение

Плагин ktlint в `pom.xml` **не добавлен** намеренно: у Maven-плагина нет цели
`generateBaseline`, отпечаток он не умеет, а встроенный `--baseline` не работает.
Один источник правды — скрипты в `tools/`.
