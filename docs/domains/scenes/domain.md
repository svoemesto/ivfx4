# Домен: Сцены и события

## Обзор контекста (Bounded Context)

Сцена и событие — смысловые группы планов: сцена —драматический отрезок,
событие — то, что происходит в кадре (действие, реплика). Обе сущности
размечаются **только вручную**.

## Dependencies | Зависимости

- `shots` — сцена состоит из планов
- `filters` — условия фильтра умеют отбирать по свойствам сцен и событий

## Ubiquitous Language | Единый язык

- **Сцена**: непрерывная группа планов с общим смыслом
- **Событие**: группа планов, описывающая происходящее
- **План в сцене**: план целиком внутри диапазона кадров сцены

## Публичные контракты (API)

### Internal API (для других модулей системы)

`controllers/SceneController`, `controllers/EventController` — создание,
переименование, объединение, удаление.

## Domain Invariants | Инварианты и правила бизнеса

- **Связи с планами в базе нет.** Принадлежность плана к сцене вычисляется
  сравнением диапазонов кадров: план целиком внутри диапазона сцены.
- Поле `parentId` объявлено, но **никогда не заполняется**.
- При удалении файла сцены и события остаются сиротами: у `File` нет полей
  `scenes` и `events`, каскад их не покрывает.

## Структура компонентов (C4 L3)

- `models/Scene.kt`, `models/Event.kt`
- `controllers/SceneController.kt`, `controllers/EventController.kt`
