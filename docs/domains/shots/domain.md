# Домен: Планы

## Обзор контекста (Bounded Context)

План — непрерывный фрагмент видеоряда между двумя границами. Границы находит
алгоритм по метрикам соседних кадров, но окончательное решение принимает
оператор.

## Dependencies | Зависимости

- `frames` — границы вычисляются по метрикам кадров
- `scenes` — сцены объединяют планы
- `filters` — планы это то, что отбирается фильтром и вырезается в экспорт

## Ubiquitous Language | Единый язык

- **План (shot)**: фрагмент от первого до последнего кадра включительно
- **Тип плана**: сколько людей в кадре — один, через плечо, двое, трое и
  более, очень много
- **Ручная граница**: граница, поставленная оператором, имеет приоритет над
  найденной алгоритмом
- **Разрыв плана**: union — два плана объединяются в один

## Публичные контракты (API)

### Internal API (для других модулей системы)

`controllers/ShotController` — создание, разбиение, объединение, выборка по
фильтру, вырезание видео.

## Domain Invariants | Инварианты и правила бизнеса

- План не пересекается с другим планом того же файла: границы общие.
- Тип плана — один на весь план, не на кадр.
- Ручные границы хранятся отдельно от найденных алгоритмом: повторный
  анализ кадров не должен затирать правку оператора.
