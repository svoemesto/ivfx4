# Система: контекст (L1)

## Что это

Настольное приложение для кинематографического анализа видеоархива.
Работает на одной машине, одного пользователя, сетевого взаимодействия нет.

## Актёры

| Актёр | Что делает |
|---|---|
| **Оператор** | создаёт проект, добавляет файлы, запускает обработку, правит результат, собирает выборку |
| **MediaInfo** | внешняя программа, читает состав дорожек файла |
| **ffmpeg / ffprobe** | внешние программы, кадры, превью, нарезка, склейка |
| **Python + InsightFace** | внешний процесс, детекция и распознавание лиц |
| **Система управления БД** | хранит проект, файлы, кадры, планы, лица, фильтры |

## Данные на входе и выходе

**Вход**: видеофайлы из папки оператора; прочие файлы (модели лиц, скрипты)
подтягиваются автоматически.

**Выход**: база с размеченным архивом — планы, сцены, лица, персоны;
нарезанные видеофайлы планов; склеенные файлы выборок по фильтрам.

## Границы

- **Внутри**: разбор видео, кадры, планы, сцены, лица, фильтры, свойства.
- **Снаружи**: всё остальное. Приложение ничего не публикует и никуда не
  отправляет — это локальный инструмент.
