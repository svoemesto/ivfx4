# Рецепты

## Для оператора

| Задача | Где в интерфейсе |
|---|---|
| Создать проект | Правка → имя, короткое имя, папка, параметры вывода |
| Добавить файлы | Кнопка «+» или добавление всей папкой |
| Запустить обработку | Actions ▸ Project Actions… → отметить операции → Do actions |
| Задать границу плана | Двойной клик по миниатюре кадра в редакторе планов |
| Задать тип плана | Кнопка в колонке → выбор пиктограммы |
| Привязать лицо к персоне | Контекстное меню миниатюры лица либо перетаскивание на строку персоны |
| Создать лицо вручную | ПКМ по кадру ▸ Edit frame faces → нарисовать прямоугольник |
| Собрать выборку фильтра | Edit filters → условие → выбрать файлы → `>>` → Create Video File |

## Для разработчика

| Задача | Команда |
|---|---|
| Проверить FXML и контроллеры | `bash tools/check-fx-wiring.sh` |
| Проверить документацию | `python3 docs/scripts/lint-docs.py` |
| Собрать | `~/.local/opt/apache-maven-3.9.16/bin/mvn -q clean compile` |
| Запустить | `bash run-old-app.sh` |
| Скачать модели лиц | `bash tools/fetch-models.sh` |
| Забрать задачу | `./tools/tracker.sh claim-issue <NNN>` |
