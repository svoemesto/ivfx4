## Context & Problem | Контекст и проблема

Распознавание лиц использует две модели: SCRFD-10G для детекции
(`det_10g.onnx`, 17 МБ) и ArcFace для эмбеддингов (`w600k_r50.onnx`, 167 МБ).
Всего 184 МБ.

Изначально они лежали в `src/main/resources`, то есть в git. Это раздувало
каждый клон файлами, которые не меняются ни разу.

## Decision | Решение

Модели **не коммитятся**. Они скачиваются один раз и кешируются на машине.

```bash
bash tools/fetch-models.sh              # ~275 МБ, идемпотентно
bash tools/fetch-models.sh --force      # перекачать заново
IVFX_MODELS_DIR=/path bash tools/fetch-models.sh
```

Кеш по умолчанию — `~/.insightface/models/buffalo_l`. Это не произвольный
каталог: именно туда библиотека insightface раскладывает пакет `buffalo_l`,
поэтому наш кеш и её кеш совпадают и повторной загрузки не будет.
Путь переопределяется переменной `IVFX_MODELS_DIR`.

`FaceDetection` предоставляет `MODELS_DIR`, `modelPath(name)` и
`missingModels()`; `DetectFaces` и `RecheckFaces` берут пути оттуда.
`.gitignore` исключает `*.onnx`.

Источник — пакет `buffalo_l` из релиза InsightFace v0.7. Проверено 2026-10-07:
скачанные файлы совпали побайтово с теми, что раньше лежали в репозитории
(`det_10g.onnx` → `5838f7fe…`, `w600k_r50.onnx` → `4c06341c…`).

## Rationale | Обоснование

184 МБ неизменяемых бинарников в git — плата за то, что не менялось никогда.
Кеш в каталоге библиотеки выбран ещё и потому, что исключает двойное
хранение: insightface не скачает модель повторно, если она уже на месте.

Из архива распаковываются только два нужных файла; остальные три
(`1k3d68`, `2d106det`, `genderage`) приложение не открывает.

## Consequences | Последствия

**Отрицательные**

- Первый запуск на новой машине требует сети и ~275 МБ трафика.
- Без моделей не работают `DetectFaces`, `RecheckFaces`, `RecognizeFaces`.
  Остальное приложение работает как обычно.
- Модели, уже попавшие в историю git, оттуда не исчезли: коммит `841c886`
  их содержит. Убрать оттуда можно только переписыванием истории.

**Положительные**

- Клон репозитория лёгкий.
- Модель всегда свежая относительно указанного релиза, а не «как было
  закоммичено неизвестно когда».

**Что делать при изменении**

- Вернуть модели в `src/main/resources` нельзя — это ровно то, что убрано.
- Новые модели добавляются в `MODELS_REQUIRED` и в `tools/fetch-models.sh`,
  иначе `missingModels()` о них не узнает.
